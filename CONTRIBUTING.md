# Contributing

This is a demo, published from a private repository. Only GentleBits can change this repository; you are free to fork
it and change your own copy (MIT, see [LICENSE](LICENSE)).

- **Issues:** bugs and questions are welcome as issues. They are read, but there is no support and no answer is promised.
- **Pull requests** are not merged here: this repository only receives the private one's publications.
- **Tests need no key.** `scripts/setup.sh`, then `uv run pytest` (the app server's tests included) and
  `cd web-ts && npm test`. The first run builds the tests' own index (about two minutes).
- **Never put a key in an issue, a commit or a test.** Tests use fake keys and pi-ai's faux model.
